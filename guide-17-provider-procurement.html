Provider Procurement

How ECMS tracks a prospective FCC Provider's application and vetting process before it becomes a real Affiliation, and how DOE tracks funding opportunities (RFPs/RFIs) for new providers — confirmed live, including a real approval validation rule.

5 steps~7 min readPhase 1Persona: ECMS Internal Admin (DECE)

Overview

Two objects drive this module: Family Childcare Application (ECMS_Family_Childcare_Application__c) tracks a single prospective FCC Provider's vetting journey through an 8-stage path (Submitted → Pending DECE Verification → DECE Verified → Affiliation Processing → Ready for DECE Approval → Pending DECE Approval → Approved / Rejected), and RFP RFI Tracking (ECMS_RFP_RFI_Tracking__c) tracks funding solicitations (Request For Proposal / Request For Information) independently of any one provider. This is distinct from the FCCN Network & Provider Setup guide, which covers the backend result (an internal user directly creating the Account/Affiliation records) rather than this pre-affiliation application/vetting process.

1Internal-only: no vendor portal access

Phase 1 framed parts of this module as a “Vendor Administrator View” (viewing affiliated networks, tracking vetting status, creating an application). A live check of both the CBO and FCCN vendor portal navigation — Home quick-actions and the More menu — found only Student Screening, Report Incident, and CheckList. There is no Procurement, Application, or Affiliated Networks entry point in either vendor portal.

Scope note. Same finding as the Coaching Log guide — in the current system, creating or tracking a Family Childcare Application and RFP/RFI appears to require internal (DECE) Salesforce access, not self-service through the vendor portal.

2Create an FCC Application Provider

DO From the Family Childcare Applications tab, click New.

RESULT A form opens in two sections: Affiliation Processing Checklist (OCFS License Number, Accis Program Number, DECE Site ID, MySchools ID, Health & Safety Check Passed) and Program Details (Program Name/Address, Services Provided, Primary Program Language, hours). The only strictly required field is a FCC Network Name lookup to an Account.

DO Fill in the Program Name, OCFS License Number, and FCC Network Name, then Save.

RESULT ECMS confirms “Family Childcare Application ‘FCA - 0000000000’ was created”, defaulting to Application Status = Submitted — confirmed live. The saved record also surfaces a built-in Questionnaire section (5 pre-screening questions, e.g. “Do you currently hold a valid license/registration as a family or group family care provider?”) and a PSI Entry Form action, neither of which was explored further for this guide.

3Approve FCCN Applications — a real validation gate

DO On a freshly-submitted application, click ahead on the path bar to Approved and click Mark as Current Application Status.

RESULT ECMS blocked the save with a real, specific validation error: “You encountered some errors when trying to save this record. Please verify all Accis, MySchools, Site, & OCFS Id's are populated. Also, please have the Network verify that all checkboxes under ‘Affiliation Processing Checklist’ are checked in the ECMS Portal.” This confirms “Approve FCCN Applications” isn't just a path click — there's a genuine prerequisite-data gate before an application can be marked Approved.

Interesting cross-reference. The error message itself references “the ECMS Portal,” implying the Network is expected to check off Affiliation Processing Checklist items somewhere vendor-facing — which doesn't line up with Step 1's finding that Procurement has no vendor portal presence today. Worth clarifying with the team whether that checklist step moved internal-only, or whether there's a portal path this guide didn't find.

4Track RFPs and RFIs

DO From the RFP RFI Trackings tab, click New.

RESULT A simple form: Request Title, required Type (Request For Proposal / Request For Information), required Start Date, optional End Date, required Budget Amount, Status (Draft, Submitted to the City for posting, Active, Requesting Clarification, Complete, Vendor Chosen, Cancelled, defaulting to Draft), and a free-text Description.

Not independently saved for this guide. The Type field's picklist widget couldn't be reliably driven through browser automation for this session, so a fully-saved example record wasn't captured — the fields themselves are confirmed live via the object's own describe metadata (Status__c, Type__c, Budget_Amount__c, etc.), just not an end-to-end save.

5Utilize Account features

Phase 1's “Utilize Account Features” topic maps to what's already documented in the FCCN Network & Provider Setup guide: an FCCN/Provider Account's related lists include Site Master, Incident Cases, Enrollments, Affiliations, and — confirmed in this guide — Family Childcare Applications. Viewing an FCCN Network's affiliated Providers (Phase 1's “View FCCN Affiliated Networks”, vendor-side) is the same Affiliations related list already covered there, just from the opposite direction.
