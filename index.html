Coverage. All 11 guides above are illustrated end-to-end with real screenshots from the ECMS UAT sandbox, following one continuous running example (Cedar Point Early Childhood Academy for the CBO track, Riverbend Family Childcare Network for the FCCN track) wherever the workflow allowed it, so the guides can be read either standalone or as one connected story. Several guides also cover deeper features found via a cross-reference against the signed and draft Phase 2 BRDs and Jira corpus (Site Closure/Reopen, Vendor Staff Tracking, Seat Planning, SDY+/176-day limits, Advance Payment Invoices, Central Approval, Admit Codes, ACCIS eligibility, auto-approval, and the full Enrollment Change Request family) — each such addition cites its source Jira key inline.
